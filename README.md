# 📊 Atividade Plus

Aplicação web desenvolvida como MVP para apresentação acadêmica, com o objetivo de coletar e analisar avaliações de clientes em estabelecimentos.

## 🚀 Tecnologias utilizadas

### Backend
- Java
- Spring Boot
- JPA / Hibernate

### Frontend
- HTML
- CSS
- JavaScript

## 👨‍💻 Responsabilidades

- **Backend:** Desenvolvido por mim Murillo Malheiros  Alves
- **Frontend:** Desenvolvido em colaboração com Matheus Lira/github.com/Matheusvc

## 📌 Funcionalidades

- Registro de avaliações de clientes
- Armazenamento de dados
- Geração de métricas e resumos (dashboard)
- Sistema básico de autenticação

## ⚠️ Observações

Este projeto foi desenvolvido como um **MVP (Minimum Viable Product)** para fins acadêmicos, podendo conter simplificações em relação a uma aplicação de produção.

## ▶️ Como executar

### Backend
1. Acesse a pasta `/Backend`
2. Execute o projeto Spring Boot

### Frontend
1. Acesse a pasta `/Frontend/Site`
2. Abra o arquivo `index.html` no navegador
